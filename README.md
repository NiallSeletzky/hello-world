# hello-world

This repository now includes a simple wireframe D20 dice roller written in Python.

## Requirements

* Python 3.9+
* `pygame` (install with `pip install pygame`)

## Running the roller

```bash
python d20_wireframe.py
```

Use the **space bar** to trigger additional rolls. A highlighted triangle on the wireframe corresponds to the active face, while the on-screen text reports the roll result.
